## Colliding Blocks
---
Small project to compute Pi using elastic block collisions and to learn more about Vim, C and raylib.

Inspired by [3Blue1Brown](https://www.youtube.com/@3blue1brown)'s videos with the [demonstration](https://www.youtube.com/watch?v=HEfHFsfGXjs) and the [proof](https://www.youtube.com/watch?v=6dTyOl1fmDo).
